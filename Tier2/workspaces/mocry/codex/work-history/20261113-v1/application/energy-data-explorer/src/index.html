口径、覆盖范围与更新说明

ND（National Demand，全国需求）与 TSD（Transmission System Demand，输电系统需求）分别展示原始实绩和对应官方预测。预测取目标日开始前 23:59:59 UTC 时已公开的 NDF / TSDF 全国版本，经 Elexon BMRS 提供；只对完整 48 个半小时求日均。缺失保留断线，不插值、不填零。实绩也按同一 UTC 日聚合。

“原实验 ND 特征点均值”是此前模型输入的摘要，非全天时间加权均值，与新加入的半小时预测曲线分开显示。新数据仅加入可视化，既有训练结果保持原版本。
