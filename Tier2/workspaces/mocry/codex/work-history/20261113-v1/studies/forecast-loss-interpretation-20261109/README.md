# Train/val loss 的年份与波动差异

本说明由既有冻结实验数据追加计算，没有训练、调参或改动原交付包。

训练数据年份为 2020–2022。使用最长 56 日窗口后，实际参与训练 loss 的目标日期为 2020-02-26 至 2022-12-31，共 1,040 个样本。验证目标为 2023-01-01 至 2023-12-31，共 365 个样本。两个分区使用同一训练期标准差，loss 均为每样本平均值。

## 数据难度的证据

在相同预测起点上，电价“明天等于今天”的日变化 RMSE（£/MWh）分别为：2020 年 11.043；2021 年 47.544；2022 年 45.349；2023 年 20.029。训练期合并 RMSE 为 39.388，验证期为 20.029。训练期的 2021 和 2022 年贡献了约 97.7% 的照抄基准平方误差总量。这是当前数据集中的现象，不需要以模型拟合来解释。

照抄基准电价标准化 MSE 从训练的 0.172330 降至验证的 0.044562，约相差 3.87 倍；RNN 从 0.142748 降至 0.038269，约相差 3.73 倍。因此电价 val loss 远低于 train loss，主要与年份的实际日变动幅度不同相符，不是因为验证样本数较少，也不是分别按各集合标准差重算。

相对同分区照抄基准，RNN 电价在训练期改善 17.17%，验证期改善 14.12%。所以较低的绝对验证 MSE 不表示验证期相对预测能力更强。

供给的方向不同：照抄标准化 MSE 训练 0.363113、验证 0.457790；RNN 为 0.112168、0.244418。验证年份的供给日变化较大，模型相对基准的改善也从 69.11% 降至 46.61%。这显示跨年数据差异和模型泛化变化，不能只把全部差额叫作过拟合。

## 与训练过程过拟合的区别

过拟合判断还应看固定 train/val 上随 epoch 的变化。此前价格 RNN 在最佳验证点之后，train loss 从 0.142748 继续降至 0.126181，val loss 从 0.038269 回升至 0.048951。这是支持早停的具体过程证据，尽管 val 的绝对数值仍低于 train。

数据来源：原独立目标试验 inputs/model_daily.csv、splits.csv、results/LOSS_COMPARISON.csv；年度照抄分解见 YEARLY_PRICE_DIFFICULTY.csv。原模型、权重、协议、ZIP 和历史结果均未改。
