# Tier 2A 与 Tier 2B 可运行模型（日尺度）

2026-11-16 · MMCS Group 15 · 个人研究稿与复算材料，不是小组决定

两条 Tier 2 路线各做了一个可运行的模型，沿用 Tier 1 v6 的数据和口径，当时用于选路线时对照。金额为 2020 年英镑。结果由 SciPy 自带的 HiGHS 求出，Xpress 分支尚未运行，见"复算"。

小组后来走的是半小时粒度的 2B 路线（预测加滚动调度，固定一个 100 MW / 400 MWh 电池）。本稿是日尺度、无电池的另一种做法，可作为旁证，不是替代方案。

## 结论和取舍

### 2A：新增发电投资

| 问题 | 本轮证据 |
|---|---|
| 投哪种发电 | 任何预算下海上风电都是零，本模型的平准化成本 £72/MWh 高于能实现的收入 £62/MWh。陆上风电先进场，饱和后才是光伏。 |
| £5 亿预算怎么分 | 352 MW 陆上风电加 23.3 MW 电解槽，零电池。年净收益 A £44.14m、B £34.19m，其中高于 Tier 1 的部分为 £31.40m、£31.73m，回收期 6.6 年、7.6 年。 |
| 收益递减 | 每多投 £1 的年净回报：前 £1 亿约 6.9%，£10–20 亿约 5.3%，£20–40 亿约 2.8%，£40 亿以上约 0.5%。不设预算时停在 3.4 GW 陆上风电加 1.8 GW 光伏。 |
| 新增发电是否改变电解槽和电池 | 不改变。所有预算下电解槽都是 23.3 MW，电池都是零。电解槽规模由氢的销量决定。 |
| 结论对什么敏感 | 电价最敏感：电价减半时不建任何发电。Arup 高成本情景下改为 710 MW 光伏。剔除 2021–22 年后选择不变，年净收益从 £44.1m 降到 £24.8m。 |

### 2B：有限信息下的逐日运营

| 问题 | 本轮证据 |
|---|---|
| 没有电池时，时间顺序靠什么起作用 | 试了两个机制。氢气缓冲罐不成立：钢罐要便宜约 95% 才会被选中。成立的是承购合同的结算窗口：买方按 W 天的总量结算，生产可以挪到窗口内便宜的日子。 |
| 窗口值多少（完全预知，全历史） | 结算窗口 1、7、28、365 天时，A 的年净收益为 £12.74m、£12.91m、£13.21m、£15.27m。周合同只多 1.3%。 |
| 不靠预知能拿到多少（A，2023–25） | 日合同 £13.08m。周窗口下贪心 £12.48m、价格阈值 £12.74m、滚动规划朴素预测 £12.84m、滚动规划岭回归 £12.95m、完全预知 £13.24m。所有可实现的规则都不如日合同。 |
| 原因 | 预测能力两天就没了。电价平均绝对误差提前 1 天为岭回归 £11.2、朴素 £13.5，提前 3 天起持平。 |
| B 下的情况 | 只用余电时贪心就是最优，不需要预测。2023–25 年净收益从 £0.93m 升到 £1.19m（周）或 £1.26m（月）。 |

## 实现与口径

- 2020–2025 年共 2,192 天。供给为全国总发电加独立风电场，全国需求为售电上限。电价折到 2020 年英镑，实际折现率 5%，氢净回价 £7.80/kg，氢销量上限 10 t/天。
- 电解槽按连续 MW 计，所以 Tier 1 的复现值是 23.29 MW 和 £12.74m、£2.46m；v6 是整数台带最低负荷，为 23.42 MW 和 £12.68m、£2.44m，相差 0.5% 以内。
- 电池用 Tesla Megapack 2XL 的单位成本，按连续 MWh 计，只在策略 A 下开放。
- 2A 的发电成本取自 Arup 为 DESNZ 做的 2024 年成本更新中间情景。逐日出力形状来自课程数据，再缩放到该来源的负荷因子。
- 2A 的策略 A 是一个线性规划。策略 B 下是否有余电取决于新增容量，用不动点迭代求解，再用闭式逐日调度核算。
- 2B 的电解槽容量用 2020–22 年在完全预知下选定后冻结，2023–25 年逐日回放，各规则只能看到过去。

## 局限

- 日数据看不到日内价差，无法评估电池的日内套利。
- 2B 的预测器是简单的岭回归。仓库里已有更强的预测模型，可以替换 `tier2b.py` 里的 `Forecaster` 类重跑。
- 结算窗口是假设的谈判条件，没有来自买方的证据。
- 2A 是价格接受者模型，GW 级新增风电会压低电价，大预算下的收益偏乐观。

## 复算

需要 Python 3.10 以上，以及 numpy、pandas、scipy、scikit-learn、matplotlib。在本目录运行。

```sh
python tier2a.py --check     # 复现 Tier 1：23.29 MW 电解槽，A/B 年增益 12.74 / 2.46
python tier2a.py             # 约 10 秒
python tier2b.py --check
python tier2b.py             # 约 40 秒
```

**关于 Xpress。** 两个模型都是线性规划。`common.LP` 里有 `--solver xpress` 分支，用 Xpress Python 接口建同一个模型，但从未运行过。请先运行 `python tier2a.py --solver xpress --check`，确认与上面的数字一致后再引用。
