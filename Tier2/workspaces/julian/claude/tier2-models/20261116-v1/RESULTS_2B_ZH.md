# Tier 2B 结果：有限信息下的逐日运营

## 出发点

Tier 1 的结论是只建电解槽、不建电池，氢按每天 10 吨的上限卖出。没有储能时每天独立求解，时间顺序和预测都不起作用。2B 要有内容，先得找到一个让"今天的决定影响明天"的机制。这里试了两个。

## 机制一：氢气缓冲罐（不成立）

把电解槽和储罐一起优化，储罐用小组调研的 DEA 钢罐成本（约 £185/可用 kg·年）：

| 储罐成本 | 策略 A 选的储罐 | 策略 B 选的储罐 |
|---|---:|---:|
| 调研成本 | 0 | 0 |
| 调研成本的 25% | 0 | 0 |
| 调研成本的 5%（接近盐穴） | 20 吨 | 26 吨 |
| 免费 | 4,202 吨 | 5,435 吨 |

钢罐要便宜 95% 左右才会被选中。这条路走不通。

## 机制二：承购合同的结算窗口（本模型的主体）

不买储能，改合同：买方接受的量不变，但按 W 天的总量结算（W = 1 就是 Tier 1 的日合同）。生产可以挪到窗口内最便宜的日子，前提是电解槽留有余量。操作员每天面对的正是讲师描述的问题：今天用掉配额，还是留给可能更便宜的明天。

- **设计**：电解槽容量用 2020–2022 年在完全预知下选定，然后冻结。
- **运营**：2023–2025 年逐日回放，各策略只能看到过去。
- **对照策略**：按日均摊；贪心；价格分位阈值；滚动规划（朴素预测）；滚动规划（岭回归预测，每年初重估）；完全预知。

## 主要结果

**1. Tier 1 方案沿时间看，两种策略差别极大。**

| | 策略 A | 策略 B |
|---|---:|---:|
| 回本日期（2020 年初投资） | 2022 年 4 月 | 六年内未回本 |
| 有产出的天数占比 | 89% | 21% |
| 最长连续停产 | 36 天 | 302 天 |
| 年净收益为负的年份 | 无 | 2021、2023、2024 |

策略 B 下电解槽只吃余电，一年里五分之四的日子停着。任何需要稳定供氢的买方都不会接受。

**2. 合同窗口的价值，在完全预知下也不大。** 全历史：

| 结算窗口 | 策略 A 年净收益 £m | 电解槽 MW | 策略 B 年净收益 £m | 电解槽 MW |
|---:|---:|---:|---:|---:|
| 1 天 | 12.74 | 23.3 | 2.46 | 23.3 |
| 7 天 | 12.91 | 27.2 | 2.72 | 32.6 |
| 28 天 | 13.21 | 31.1 | 3.11 | 38.4 |
| 365 天 | 15.27 | 47.6 | 5.92 | 76.8 |

周合同对策略 A 只多 1.3%。

**3. 策略 A 下，没有预知能力时周合同反而更差。** 2023–2025 年，年净收益 £m：

| 运营方式 | 7 天窗口 | 28 天窗口 |
|---|---:|---:|
| 日合同（Tier 1） | 13.08 | 13.08 |
| 贪心 | 12.48 | 12.11 |
| 价格阈值 | 12.74 | 12.93 |
| 滚动规划，朴素预测 | 12.84 | 12.91 |
| 滚动规划，岭回归 | 12.95 | 12.76 |
| 完全预知 | 13.24 | 13.44 |

完全预知能多赚 £16–37 万/年，但所有现实可行的策略都比日合同少赚 £12–97 万/年。多出来的电解槽容量每年要花约 £58 万，预测抓不回这笔钱。

**4. 原因是预测能力两天就没了。** 电价的平均绝对误差：提前 1 天岭回归 £11.2、朴素 £13.5；提前 3 天起两者持平。供需差额也是提前 1 天有优势（34 对 42 GWh），到第 7 天基本消失。周窗口需要的恰恰是一周后的信息。

**5. 策略 B 下周合同有用，而且不需要预测。** 只吃余电时，贪心就是最优（模型里贪心和完全预知结果相同）。2023–2025 年净收益从 £93 万升到 £119 万（周）或 £126 万（月）。绝对值很小。

## 什么会改变结论

策略 A、周合同、滚动规划相对日合同的差额（£m/年）：

| 情景 | 差额 |
|---|---:|
| 中间情景 | −0.12 |
| 氢净回价 £6/kg | −0.14 |
| 氢净回价 £10/kg | −0.55 |
| 电解槽成本 −30% | −0.13 |
| 电解槽成本 +30% | 0.00（不再加大电解槽） |
| 销路 100 吨/天 | −1.40 |
| 电价 ×0.5 | −0.35 |
| 电价 ×1.5 | +0.05 |
| 电价波动翻倍 | −0.31 |

九个情景里只有一个勉强为正。结论稳健。

## 给客户的建议

- **策略 A**：保持日合同，用最简单的规则运营，即电价低于 £139.5/MWh（氢的盈亏平衡点）就开机。不要为了灵活性加大电解槽，也不值得为这台设备建预测系统。
- **策略 B**：如果必须先供电，和买方谈周或月结算，收益提高约三成，运营规则是"有余电就产"。但策略 B 本身回不了本。
- **储氢罐**：现有成本下不建。

## 局限

- **日数据看不到日内价差。** 小组的半小时筛查显示电池的大部分套利价值在日内，本模型无法评估。
- **预测器是简单的岭回归。** 小组已有更强的预测模型（需求均方误差降了约 38%），可以直接替换 `tier2b.py` 里的 `Forecaster` 类重跑。这也正好补上仓库里记录的缺口：预测改进尚未转化成运营利润对比。
- **合同窗口是一个假设的谈判条件**，没有来自买方的证据。
- **训练期 2020–2022 包含能源危机**，按它选的容量对 2023–2025 不一定最优；表中另列了事后最优设计作对照。
