## 结论和取舍

| 问题 | 本轮证据 |
|---|---|
| Tier 1 的"只用余电"方案能运行吗 | 用现实的电解槽不能。最短运行 5 天且不允许用其他电力时，40 MW 电解槽只有 7% 的日子在运行，每年亏 £609 万。余电够一个模块连续用 5 天以上的情况每年只有 3.8 次。 |
| 怎样才可行 | 为最低负荷提供稳定电源。只允许用可售电或外购电托住最低负荷时，同一座 40 MW 每年赚 £447 万（回收期 6.7 年）。此时最优规模为 340 MW、每年 £1,726 万，但一半的氢来自本来有买家的电，六年里三年亏损。 |
| 时间顺序会改变转用情景吗 | 几乎不会。最优规模 660 MW，每年 £1.278 亿，回收期 5.2 年。5 天最短运行的代价不到 1%。 |
| 最短运行的长度有多重要 | 只用余电时是决定性的（2 天就已亏损）。其他情况下是次要因素：5 天损失 1–2.5%，28 天不到 10%。 |
| 要不要建电池 | 不建。电量逐日传递后，每 MWh 每年价值 £2,100–4,300，在替代外购电的情形下最多 £14,200，而成本是 £27,400。 |
| 应该怎样运行 | 从简。氢价 £9.5/kg 时，"从不停机"在 2022–2025 年拿到完全预知结果的 94–96%，差额几乎全在 2022 年。完美的 7 天预测就能完全补上这个差距。 |
| 更好的预测值得吗 | 在这里不值得。NESO 日前风电预测把风电场出力的一日误差降低 24%，但基于回归预测的计划反而不如基于持续性预测的计划，因为点预测低估了余电（0.9–1.0 对 2.5 GWh/天）。 |
| 什么时候运行水平重要 | 氢价接近电价时。£6/kg 时"从不停机"拿到完全预知的 76–77%，每天重新规划拿到 84–87%。 |
| 什么会改变策略 | 氢价（托底方案在 £7/kg 时消失，转用方案在 £5/kg 时消失）；全国需求与可再生出力之间的平衡（需求高 10% 托底方案就不成立，低 10% 则达到 820 MW）；氢的销量，受限时由它决定规模（10 吨/天对应 20 MW）。电解槽造价和折现率改变规模，但不改变是否投资。最短运行的长度、启动成本、外购电附加费和年份选取影响很小。 |

## 实现与口径

- **时序模型**（`t2b_model.py`）。每天运行的模块数（整数）、启动数、三个来源的电量（余电、风电场可售电、电网），可选的电池（电量逐日传递）和可选的氢销量上限。中心情景为最短运行 5 天，每个运行模块最低负荷 20%。
- **三种用电规则**：只用余电；余电加上只用于托住最低负荷的其他电力（"托底"）；风电场的可售电只要划算就转用，外购电只用于托住最低负荷。
- **滚动运行。** 每天的开机模块数在前一天晚上决定：用最新的预测，对未来 7 天求解模型。当天再按实际情况运行。评分区间为 2022–2025 年。
- **预测**（`t2b_forecast.py`）。持续性预测；每月重新估计的岭回归；第一天另外加入 NESO 日前需求和风电预测的回归；以及对过去预测误差取平均来计算余电的版本。全部只用预测当天已知的信息。
- **口径。** 风电场边界、2023 年英镑、实际折现率 8%、电解槽 £2.0m/MW（20 MW 整台）、两小时电池 £24.5 万/MWh、氢价 £9.5/kg，均与独立 Tier 1 相同。非余电按当天市场电价计成本。

## 复算

需要 Python 3.10 以上，以及 numpy、pandas、scipy、matplotlib。在本目录运行。

```sh
python t2b_run.py --check                  # 一致性检查，约 20 秒
python t2b_run.py                          # 全部阶段和出图，双核约 45 分钟
python t2b_run.py --stage rolling figs     # 只跑指定阶段；结果缓存在 results/
```

**关于 Xpress。** 题面要求主要建模用 Xpress。`--solver xpress` 通过 Tier 1 的辅助函数把同样的矩阵交给 Xpress，但这个分支从未运行过。请先在有许可的机器上运行 `python t2b_run.py --check --solver xpress`，全部检查通过后再引用结果。

## 核对过的内容

- 自由开关加只用余电时，模型复现 Tier 1 的调度结果（40 MW 时 £0.709m）。
- 在 18 个随机的 9 天窗口上，模型与穷举所有开机路径的结果一致。
- 对最优开机计划用闭式的逐日规则运行，现金与模型一致。
- 用完美的 28 天预测每天重新规划，复现完全预知的最优解。
- 最短运行更长时最优值不会更高，规则更宽松时最优值不会更低。

## 局限

日粒度看不到一天之内发生的事，包括电池套利，还会高估余电的连续性；结论不一致时应以半小时模型为准。风电场边界是一种解读。中心情景里外购电按批发价计。外购电制的氢与余电制的氢按同一价格计。官方预测只有日前一档。详见 [RESULTS_ZH.md](RESULTS_ZH.md) 第 6 节。
