# Tier 2B update · in-12h-exact v1 and v2

Ran Min's 19 November forecasting and dispatch work is available in release `a29c3f2`. Both versions forecast the next 24 half-hours from the same 76 input features and can be run with the public Safetensors weights. [Model directory and inference instructions](../../public/models/README.md)

- **v1 is the frozen feature-engineering benchmark.** We screened input sources and representations, then retained the original 59 channels plus forecast-shape features, INDGEN and TSDF. v1 uses a 1×768 Transformer for generation, Ridge for demand, and Ridge followed by a 1×864 Transformer for electricity prices. [v1 model card](../../public/models/ensembles/in-12h-exact-v1/README.md) · [Feature-engineering and v1 research history](../../workspaces/mocry/codex/work-history/20261119-in-12h-exact-v1/README.md)
- **v2 is the current highest-accuracy released ensemble.** With the inputs frozen, we tested depth and width, attention and feed-forward operators, and target-specific readouts. v2 averages v1 with separate price, generation and demand branches. Across the three test windows, standardized 12-hour path MSE fell from **0.043761 to 0.041105 (6.07%)**. The same recipe trained with six new seeds reduced pooled MSE by **7.00%**. [v2 model card](../../public/models/ensembles/in-12h-exact-v2/README.md) · [Architecture and v2 research history](../../workspaces/mocry/codex/work-history/20261119-in-12h-exact-v2/README.md)
- **Forecast gains translated differently under the two dispatch policies.** In the three-window replay, equipment and rolling 12-hour model predictive control were held fixed. At the common £4.695m annualized battery cost, v2's combined net battery increment was **£0.334m under A** and **£1.006m under B**. Compared with v1, the paired changes were **+£203k under A** (95% interval +£90k to +£299k) and **−£92k under B** (−£229k to +£27k).
