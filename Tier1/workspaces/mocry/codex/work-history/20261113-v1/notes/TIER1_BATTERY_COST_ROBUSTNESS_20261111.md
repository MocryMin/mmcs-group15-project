# Tier 1 零电池结果的成本范围

2026-11-11。以 v6 同口径主算为基准。对 `configuration.json` 的每款电池将 `capital_GBP` 和 `fom_GBP` 乘0.5。调用同一个 `model.solve`，使用2020–2025年逐日数据，A/B分别求解。电解槽参数、购售规则、效率、库存、投运电量费用、氢承购上限和净回价沿用主算。

| 策略 | 减半成本后最优电池 MWh | 年等价增益 £m | 求解收益上界 £m |
|---|---:|---:|---:|
| A | 0 | 1638.6601356227402 | 1638.6601356227402 |
| B | 0 | 37.71245342928523 | 37.712453429282654 |

两组求解器均报告最优，使用 `verify_results.check` 对导出计划独立审计通过。B的约2.6e-12百万英镑差异为求解与收入重算的舍入。数据和结果留在 `../tmp/tier1-battery-cost-check-20261111/results/`。

设正电池组合 $x$ 相对于半成本情景增加年度成本 $\Delta C(x)$。任意含至少一台电池的组合都有 $\Delta C(x)\ge3454.98$ 英镑/年。因此 $\Pi_{\mathrm{full}}(x)=\Pi_{\mathrm{half}}(x)-\Delta C(x)\le U_{\mathrm{half}}-\Delta C(x)$，其中 $U_{\mathrm{half}}$ 是半成本模型的全局收益上界。零电池的收益在两套成本下相同，原成本下含电池方案至少差约£3,455/年。各型号年等价成本逐项不低于半成本测试点时，零电池仍是一个最优选择。

这个界限针对既定数据、目标、运行约束与收入。项目原文第1页允许选择目标和模型，第3页允许简化时间。在 v6 数据中，2020-01-21 有约1.893 GWh 当日余电，次日约20.434 GWh 缺口。若有设备预算且优先最小化缺供，1.5 MW/3 MWh参考电池可以转移约1.708 MWh到次日，直接反例说明零电池没有跨目标的保证。CU旧模型的2023年无电解槽、年度池化电池检验是另一口径的交叉参考，结果同方向，其成本阈值仅适用于对应情景。
