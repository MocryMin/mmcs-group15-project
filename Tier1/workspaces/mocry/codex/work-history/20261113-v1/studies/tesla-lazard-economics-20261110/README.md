# Tesla与Lazard经济研究 v1

2026-11-10。本轮补充研究，基于设备目录v3.1。原目录和已运行baseline保留。

- [中文报告](REPORT_ZH.md)：结论、费用边界、三套数值情景与剩余实际报价缺口。
- [Tesla原厂报价提取](TESLA_QUOTES.json)：六个存档快照，五台配置的总价/年维护，安装范围、地区和交付季度。
- [Lazard成本边界](LAZARD_BOUNDARIES.json)：规模、普通运维、保修、初始额外配置与后续增补。
- [经济输入](ECONOMIC_INPUTS.json)：两套Tesla2h价格锚点情景和一套4h行业参考；估计、币值和费用范围明确。
- [核验](QA.json)、[来源](SOURCES.json)：原件位置、URL、哈希与读取范围。
- `build_inputs.py`：从保留的快照生成上述数据并检查数量和成本关系；不联网。

Tesla维护协议不等于容量增补承诺；Lazard的普通运维行也不是维护/延保/增补全包。主参考采用NREL15年含容量增补预算，原厂例行维护不再重复添加。英国现场报价、数量折扣、4h原厂价和20年延保的真实价格未冒作已知值。

完整原PDF与检查图保存在本机`evidence/`；便捷分析ZIP提供自行撰写的报告、数值、重建入口和来源指针，不附Lazard原报告整本与页面图。研究目录尚未上传仓库，本轮未重算投资，也未展开储氢或运输。
