# 研究材料与现行输入

四主题分别为 R1 电力市场、R2 电池、R3 电解槽/氢业务、R4 金融口径/数据。本目录保存 2026-11-03 受控研究的记录和来源索引，供追溯参考；模型只读取 [inputs/parameters.json](../inputs/parameters.json) 和修复后的 `inputs/` CSV。

**价格更正：**早期 R1/R4 的数据审计和旧版本研究提及的日价格存在零成交量供应商占位和查询端点问题。当前包已使用 2026-11-04-v2 完整修复价，按半小时活跃供应商成交量加权，再取日均，并按月 CPI 折价。不得从历史研究报告重新导出旧 `prices_gbp2020.csv` 来替换当前输入。计算中的修复价 2023 年均约 £78.126/MWh，旧研究价约 £37.896/MWh；这是旧价遗漏/聚合口径问题，当前模型没有把已修复价再次翻倍。

本包不额外开放进口、无限售电或销量影响价格；这些是研究过但此候选未采用的市场扩展。氢支持值不是实际已签售价；承购上限是显式情景。

当前参数和换算逐项见 [PARAMETER_BASIS.md](PARAMETER_BASIS.md)。历史材料中相对路径指向包外研究缓存时，使用 `sources.json` 的原始 URL 和仓库固定版本追溯；本包核心运算不依赖这些缓存。
