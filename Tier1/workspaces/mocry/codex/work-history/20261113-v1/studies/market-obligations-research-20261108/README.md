# 供电缺口与直接现金责任：2026-11-08 核查

本轮为本地补充研究；未修改已发布的 v4.1、未重新优化、未上传小组仓库。课程范围 MMCS，2026/27。公开网页通过无登录态的隔离 Playwright MCP 读取；既有 MCP 浏览器被占用，使用本机已安装的 Playwright MCP 启动独立临时会话，没有接入学校浏览器。

## 当前处理决定：不引入缺乏依据的合同罚则

2026-11-08 后续讨论中，用户指出客户为假想公司，不能直接为其假设合同量或罚率。接受该约束：目前不采用合同惩罚扩展，也不为此启动历史偏差价格下载或重新优化。下文的合同公式仅保留为未采用的机制说明。此前建议优先扩展合同情景属于助手提案，现已收回其优先级。

公开调研能够验证市场机制和价格序列，不能验证这家假想公司的合同承诺、市场参与身份或责任分配。现有材料不足以确认该客户承担哪项直接惩罚；这也不是已经证明英国市场中此类责任不存在。当前 A/B 仍按既有售电与设备成本口径计算收益，需求未覆盖量继续单独报告。

## 结论与题目边界

有必要研究直接现金责任。真实市场存在偏差结算和特定履约罚款，但现有题设未指定本假想客户的电力交付合同、容量市场协议或每单位缺供赔偿率。不能把给定系统需求全部视为公司已承诺交付的电量。

原题第 2 页定义的是构造能源系统；第 3–4 页允许自行说明目标及假设。当前 A/B 将需求作为售电上限；B 固定先直接出售 `min(G,D)`，并非已经建立市场法定的全需求交付义务。

## 已核实的公开制度

1. **电量偏差结算：真实现金结算款。** Elexon 的 Imbalance Pricing 说明以每个半小时的合同量与计量量之差进行现金结算。它不是一项统一正数罚率，也不是系统需求与本模型供电之差的自动收费。谁最终承担费用仍需交易主体及合同约定。市场指数价格与偏差结算价格是不同序列。
2. **容量市场未履约：明确金融罚款。** EMRS 的 Capacity Providers 页面第 9–10 步将责任联系到容量协议、系统紧张事件及相应交付义务。参与者同时取得容量支付。因此不能只加入罚款、不加入对应收入、资格和交付约束；也不能用普通日均供需差直接识别实际系统紧张事件。
3. **电力交付合同：需进一步指定条款。** 固定电量合同可能引入补购成本、约定赔偿或平衡责任分配，但我们尚未取得适用于假想客户的合同。2026 年政府 CPPA 回应确认这是发电方与企业用电方的长期合同关系，不能据此推导任何通用赔偿率。应从公开合同范本或明确标注的分析情景进一步定义。
4. **居民停电补偿不直接适用。** Ofgem 当前公开说明主要针对当地网络运营商的供电中断责任，并明确排除全国电力短缺导致的停电。此页面不能提供本项目发电投资商的统一缺供罚率。
5. **VoLL 不是公司的统一应付罚款。** Elexon 将 Value of Lost Load 定义为供电保障的价值评估并用于稀缺定价机制；不能直接给每个构造系统缺口乘上这一数值并称为公司罚金。

## 可实现的模型接口

设 $C_t$ 为提前确定的公司交付承诺，$E_t=q_t+r_t$ 为公司实际售电/交付量。合同短缺应为

$$
\ell_t^{\mathrm{contract}}=\max\{C_t-E_t,0\},
$$

而不自动等于 $\max\{D_t-E_t,0\}$。设置 $C_t=D_t$ 是需要说明的全额供电合同情景。

若明确假设每单位未交付的额外赔偿率为 $\lambda_t$，年度目标中可加入

$$
-\frac{1}{Y}\sum_t\lambda_t\ell_t^{\mathrm{contract}}.
$$

这个形式只有在赔偿确属额外现金支出时才适用。合同收入、补购成本、偏差结算及额外违约金应按同一合同现金流处理，避免把同一笔支出计算两次。

单一价格的简化偏差结算可写成 $p_t^C C_t+p_t^I(E_t-C_t)$；这已经包含承诺收入与有符号偏差结算，不应再给同一电量重复记一份现货售电收入。该式是模型接口，不是已核实本客户具有的交易合同。

## 推荐与尚缺信息

- 保留当前无交付承诺罚则的基线，结论限于其既有业务假设。
- 原助手提案曾建议优先扩展合同情景；用户指出缺乏公司特定合同依据后，当前不采纳该扩展。未来仅在获得适用来源或用户明确选择一个合同业务情景时再讨论；有无新增投资必须使用相同合同责任进行比较。
- Tier 2B 的合同承诺与预测误差结算仅保留为未采用的备选接口，不作为当前实现要求。
- 先定义交易主体、承诺曲线、承担偏差的主体、收入规则、结算/赔偿规则、触发条件、购电或补购权限、时间粒度及上限，再校准参数。
- Elexon 公开提供半小时系统买/卖价格，但本轮仅核查机制与数据入口，未下载完整历史序列。日均课程数据无法直接还原真实半小时偏差成本；使用日度代理须标明为聚合情景。
- 容量市场情景可选，当前不优先把资格、事件及计量等额外机制全加入主线。
