# Tier 1 v5：逐日库存与市场接收量强化

2026-11-10，Ran Min / MMCS。此包实现本轮五项要求，并保留v4.1作为冻结对照。当前全样本计算为2020–2025六个完整年份、2,192天的确定性投资与逐日运行。尚未上传共享仓库，也未替换旧候选报告PDF。

## 已实施

1. 从欧洲氢能观测站三个公开年度工作簿提取英国消费量估计，用最高日均值1,558.969吨/天构造全国市场宽松上界情景；旧10吨/天只作对照。完整依据见[市场研究](research/MARKET_RESEARCH.md)。
2. 电池放电拆为售电与电解槽供电两个出口，电解槽输入为当日发电加电池供电。
3. 主模型逐日传递可用库存，禁止未来借电；六年连续衔接。首尾可用库存为零，最低SOC缓冲及投运费用沿用。
4. B先用当日发电供电，有剩余缺口时已有电池库存也必须优先供电；供电不足时不能留电给制氢/未来高价。需求已满足后才可用剩余库存制氢。
5. 整理不同规格的既有证据，并补读2/5/50MW电解槽技术表及5/50MW公开标价，见[设备候选](research/EQUIPMENT_OPTIONS.md)。本次计算仍使用原3MWh/1.5MW与20MW参考网格，其他商品尚未混入未统一的安装成本。

## 数值结果

所有数字都是现有常数氢净回价和财务条件下、参考设备集合内的最优值。收益为相对同政策零投资的年度等价增益，含资本、固定维护和换堆；不是只计氢销售额。全国上界不是客户已取得订单，尤其不证明能按支持性参考净回价售出这一数量。

|---|---:|---:|---:|---:|---:|

| 旧版对照 | 10.000 | 20 | 20 | 10.944 | 2.119 |
| 上界的1% | 15.590 | 40 | 40 | 19.287 | 3.232 |

这些情景均选零电池。降低有争议的电池维护费至原口径的一半，上界情景仍为零电池，A/B电解槽容量和上述收益不变。不能将这一结论推广到加入日内交易、其他电池收入或其他商品成本后的模型。

1.559吨/天低于当前20MW模块在20%日稳态负荷下的约1.717吨最低日产量，所以该点无法开机；这体现离散设备规格与最小负荷的共同影响，不意味着市场上没有更小设备。2/5MW候选可用于后续设备集合扩展。

上界A初始资本约£5,316.001m，年均氢产量487,559.385吨，电力需求覆盖率82.214%；B初始资本约£1,080.725m，年均氢产量19,103.686吨，需求覆盖率92.172%。A会将本可售电的一部分改制氢，因此产氢量远高于B。电池虽可参与全部新路径，最优投资仍为零。

2023少盈余压力年单独重新选容量，上界A为3,640MW、年增益£1,437.215m，B为零投资。六年共同配置与单个压力年的配置不是同一个问题。

## 与旧结果的关系

只改库存时序、允许电池制氢、强化B电池优先顺序，但保持旧10吨上限时，共同配置仍为零电池/20MW，利润复现旧版。此次规模显著变化主要来自市场接收量上界的替换。新的运行机制已用强制非零电池的小算例验证，不能因实际最优值仍为零电池而说新路径未实现。

## 核验与重跑

- 11个行为/求解器检查覆盖电池跨日制氢、禁止未来借电、B补缺口后制氢、B缺口未满禁止电池制氢、负价日B仍优先供电，以及旧固定20MW结果复现。
- 16份完整逐日计划均从导出的CSV独立核对能量、库存、接收量、优先规则和收益；所有求解均报告最优。
- 16项零电池容量选择由独立逐日解析/枚举核对；两种政策的共同配置另用原Xpress逐年重放，共12次。
- 最大流量误差约1.14e-13GWh，最大收益重算误差约3.64e-12百万英镑，见[核验记录](results/verification.json)。

本地Xpress Community许可最多5000行加列，完整六年模型有21,923变量、A30,689/B35,883条约束；全规模计算采用SciPy/HiGHS。模型保留同一矩阵的Xpress入口，小算例双求解器一致；上述年度固定容量重放可在当前Xpress许可内完成。没有按许可大小缩减数据、库存天数或容量域。
