## 3. 审核事项（RV-01…RV-09）

每条给出：严重度、我的主张、证据、对分数/决策的影响、要求的具体动作。

### RV-01（严重）研究过重、模型为零
**主张**：v1.1 覆盖的是研究阶段，占最终成绩少数项；Tier1 主体为零。**证据**：全目录无模型代码、无求解输出、无图表；`BASELINE_CANDIDATE.json` 明确 `project_solver_run: false`；`control/RUN.json` 亦为 `solver_run: false`。**影响**：题面成功要素五项中三项（建模方法、技术验证、咨询解读）未开始。**要求**：把控制层压缩为一页附录（`RUN`/`VALIDATION`/`REVIEW_DECISIONS` 提要化），本周起以模型为中心排期。

### RV-02（方法，重要）"逐日时序"定位含糊，既非 Tier1 简化口径，也可能削弱 Tier2B
**主张**：题面原文为"Tier 1 models should use a simplified treatment of time – detailed chronological operation of storage is not required at this stage"，chronology 是 2B 的内容；〔CDX〕把"每日只充或只放、通量≤一个可用窗口、初末库存一致"作为 Tier1 主模型（BL-04/BL-11 亦如此）。**影响**：①Tier1 复杂度上升但结论精度不提；②提前消耗 2B 的升级空间，"2B 相对 1 的增量"变小，反而降低扩展深度评分。**要求**：Tier1 用聚合期（月/季）能量平衡 + 效率/容量约束；把〔CDX〕的日规则保留为 2B 的子情形与保守敏感性。

### RV-03（数据，严重，〔CDX〕漏报）107 天"全部可调度燃料 = 0 MW"的报告伪影
**主张**：2022-10-17 至 2026-08-03 共 107 天，核/气/煤/油/生物质/径流/抽蓄/其他全部恰为 0 MW，当日总发电仅 1,450–17,614 MW（需求中位约 27,500 MW）。
**证据**：〔CU〕独立实现复核，107 天、9 个连续块（〔CU〕v1 记为 5 块，重算为 9 块，日期数一致）；剔除这 107 天与 2022-08-02 需求异常后：缺口 160.30 → 111.41 TWh，盈余 40.63 → 40.01 TWh。
**影响**：直接影响 B 政策——$q_t=\min(G_t,D_t)$ 在这些天把几乎全部发电判给直售，电池无电可充、电解槽无余电，**系统性压低 B 下的储能/制氢价值并抬高缺口统计**；也影响"盈余集中度"叙事。**要求**：写入 run manifest 为强制 SA-DQ 双跑（全样本 / 剔除 108 日），并在报告披露该伪影。

### RV-04（参数，重要）电解槽 CAPEX 两条证据路线差约 1.8 倍，被当成"已解决"
**主张**：〔CDX〕现代 1,270–1,651 GBP2020/kW_e（IEA 路线）与旧 672–1,329（BEIS 路线，中值 816）并存，旧值仅降级为 sensitivity。**影响**：该跨度单独即可决定"建不建电解槽"，是 H2 投资结论的第一敏感项，不应当作脚注。**另**：现代情景的堆替换仍借用旧 BEIS 绝对代理（489.61 GBP2020/kW_e，第 11/22 年）——〔CDX〕已如实标注"跨模型代理、独立不确定"，但它与 FOM、寿命一起决定 30 年现金流。**要求**：给出 CAPEX × 氢价的二维临界图（各条曲线标注来源），并在报告中把"电解槽 CAPEX 采用哪条路线"列为待决事项而非既定。

### RV-05（题面前提，严重缺失，〔CDX〕未覆盖）没有定义"上一家咨询公司的简单方案"
**主张**：题面开篇即"the client has already received a proposed solution from another consultancy but was not satisfied… challenge the assumptions behind a simple solution"，且要求"why the recommendation is better than a simpler strategy"。A0/B0 是"不投资"，不是那个简单方案。**证据**：全 v1.1 无 `consultancy` 相关表述（关键词检索为空）。**要求**：显式构造两个对照并量化 LP 增量：(a) 不投资；(b) 朴素规则（例如按日均价、每日满窗口一次循环的 50 MW 电池；或"按年盈余×转化效率"的静态容量估算）。

### RV-06（决策分析，缺失）没有阈值/临界点
**主张**：题面把"what could cause the recommendation to change"列为"very important question"。v1.1 只列了待跑情景，未给阈值。**可直接使用的三条**〔CU〕：
- 电池套利必要条件 $p_{sell}/p_{buy} > 1/\eta_{RTE} = 1/0.9 = 1.111$；同价循环每 MWh 购电净亏 $p-\eta p$（当 $p$=£48.17 时 £4.82）；
- 氢的电力等价价值 $9.4954\text{ £/kg} \div 55.9\text{ kWh/kg} = 169.95\text{ £/MWh}$ 输入电——即"氢何时打得过直售"的判据；
- FOM 取 2.9% 还是表头值，使 3 MWh 单元年固定成本为 €25,056 vs €12,528，直接移动投资临界容量。
**要求**：把三条并入"什么会改变建议"一节，并配 tornado 图。

### RV-07（财务）5% + GBP2020 可辩护，但与题面"ROI is a factor"对接不足；且跨文件基准未定
**主张**：题面明写 ROI 是每个投资者的因素；〔CDX〕给出年度等价净收益与 NPV，未给 IRR/回收期/ROI 的具体呈现方案。另：〔CU〕本轮选 7% + GBP2026，两个选择都无证据支撑；在确定基准前，A0–B1 与其他文件不可比。**要求**：报告里至少给 NPV×折现率曲线 + 回收期 + ROI，并在 run manifest 固定"一个报告基准"。

### RV-08（前瞻，若选 Tier2A 则为重大缺口）Tier2A 研究空白
**主张**：无 RE PD 项目管道、无分技术 CAPEX/LCOE、无由所给燃料数据估的容量系数、无并网/土地成本。**影响**：若团队倾向 2A，现补需 1 周以上；若选 2B，〔CDX〕的时序研究正好复用。**要求**：本周内明确 Tier2 选择，并在消息中记录；选 2A 需立即开一条发电侧研究线。
