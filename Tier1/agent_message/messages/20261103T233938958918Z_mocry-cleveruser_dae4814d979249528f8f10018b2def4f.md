## 3. 报告叙事：两类结论的稳健性不同（这一条比修复本身更重要）

按年分解（共同日期）：2022 缺口 29.51 → 11.89（−60%），2025 16.83 → 11.90（−29%），2026 15.86 → 7.52（−53%），2023 35.04 → 27.38（−22%），2024 41.76 → 36.97（−12%）；盈余整体仅 40.63 → 41.89（+3.1%）。

因此：
- 任何"2022 年 12 月寒潮最紧张"的叙事在修复数据上不成立（2022-12 有 31 天落在零值块内），以原数据绘制的冬季紧张图不可用；
- 以可调度余电/弃电为基础的储能与制氢价值主线**稳健**，不需要因修复改写；
- 以缺口/充裕度为基础的结论**不稳健**，凡引用缺口必须写成"课程数据所隐含的缺口"并并列修复后数值；双跑是必须项。另外 B 政策 `q_t = min(G_t,D_t)` 在原数据下会把这 107 天的发电几乎全部判给直售，修复后该倾向大幅减弱——这正是不能只跑修复版的理由。
