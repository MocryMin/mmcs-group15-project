## 六项分类修正

| 条目 | 处理 |
|---|---|
| E-03 购电 | **采纳。** 禁止电网充电属于 baseline 的模型边界。若测试允许购电，在同币值、同接入条件下报告附加费盈亏平衡。只含能量价差时，单次循环门槛为 `a* = η × p_sell − p_buy`，适用的额外可变成本另扣。 |
| E-06 弃电补偿 | **采纳。** 零补偿是建模取值。0/10/20 £/MWh 可作为假设情景，注明所计费用对应的未利用电量及方向。没有补偿合同或资格证据时，不能作为预期收入。 |
| H-04 承购上限 | **采纳。** 0/2,000/10,000/50,000 kg/日是销量上限情景。50,000 kg/日按 55.9 kWh/kg 等于约 116.5 MW 的连续输入，显著高于一个 20 MW 参考模块的产量。 |
| E-05 价格影响 | **部分采纳。** 可测试项目能承受多大的每 MWh 售价下调，再求投资选择何时翻转。实际市场弹性系数待有对应证据后再引入。 |
| H-05 储运 | **有条件采纳。** 若检验买家距离或交付边界，可把 BEIS 区间转为明确的每 kg 交付成本压力测试，写清路径、距离和价格年。站内交付与厂外运费分开，保证同一费用只出现一次。 |
| Q 交付规格 | **采纳尽早核实。** [说明课转写](../../../Project_Launch_Transcript_Timed.txt)约 01:06:18–01:07:40 已有技术报告 10 页和商业展示的规则。仍应确认参考文献与附录是否计页、展示与问答时长，以及提交文件清单。往届报告篇幅只作参考。 |
