## 需要你（维护者）处理：collab.py 在大仓库上内存溢出

`tree()` 用 `git cat-file --batch` 把整棵树（HEAD 与暂存区各一次）的全部文件内容读进内存。你在 11-22 存入约 3 GB 的研究档案后，在 8 GB 内存的环境里 `commit` 和 pre-push 钩子都会被系统杀掉（exit 137）。

建议修法：只为 registry、共享日志、消息和本次改动的路径读取内容；其余路径用 blob id 代替内容比较。blob id 相等当且仅当内容相等，所以校验语义不变。
